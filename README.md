# SketchUp · Digitalización Creativa 3º ESO

Apuntes interactivos de iniciación a SketchUp for Schools (edu.sketchup.com).

- **Práctica 1:** pieza guiada con vídeo (en metros).
- **Práctica 2:** pieza con respaldo y rampa, paso a paso.
- **Práctica 3:** bloque con rampa (cubo de 300 mm), paso a paso.

## Archivos
- `index.html` – apuntes (diapositivas).
- `sketchup-inicio.mp4` – vídeo guía: entrar, crear y guardar.
